# Welcome to PicoScenes GitHub Source Base

## Features to come in Q1 2025

We are working diligently on a major refactoring of the PicoScenes platform. Many exciting features are scheduled to release in Q1 2025, including:
* Highly-efficient & robust multi-thread Rx Decoding
* Flexible multi-pipeline Rx decoding, e.g., simultaneously decoding 20/40/80/160/320 MHz channels via internal spectrum masking & aggregation
* High-performance carrier splitting & aggregation for 160/320MHz channel
* high-performance Radar implementation, up to 160/320MHz bandwidth
* Support for the NI USRP TwinRx daughterboard
* Porting to the Windows platform (only for NI USRP)!
